# Changelog

## 0.2.0 — In development

- Optional curved bubble tails, combined tails/arrows, and pointer-free cards.
- Exact `sourcePoint` targeting and left/right card placements with safe-area fallback.
- Independent target outlines, continuous translucent backgrounds, touch passthrough,
  dynamic colors, movement tracking, and export exclusion for the entire bubble.
- Demo pointer-style selector, integration examples, and tail regression tests.
- Existing callers retain the automatic symbol-arrow presentation by default.
- Custom title/message fonts with optional Dynamic Type scaling, silhouette
  borders, and automatic, disabled, or fully configurable shadows.
- Gentle appearance from the target point by default, with configurable duration,
  fade-only and immediate alternatives, and Reduce Motion support.
- Paper and Night demo themes, styling/animation tests, and configuration guides.

## 0.1.0 — 2026-10-14

First public release.

- Swift Package Manager product and Xcode framework for iOS 15 and later.
- Public hint model, presenter, per-presentation options, and shared style.
- Anchored nonmodal cards, automatic arrows, and sequential presentation.
- Persistent presentation, dismissal, and completion history with namespaces.
- JSON catalogs and validation of empty or duplicate identifiers.
- Dynamic Type, VoiceOver, Reduce Motion, and right-to-left text support.
- Optional target outline and synchronous screenshot exclusion.
- Standalone demo, 19 library tests, and a demo UI test.
- MIT license, integration guide, and contribution instructions.
